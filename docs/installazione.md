# Installazione
Prima di iniziare la procedura di installazione, leggere la sezione requisiti nel [README](../README.md)

Per installare è necessario avere "git" sul proprio dispositivo

- Aprire il terminale
- Verificare che git sia installato:
    ```bash
     git --version
     ```

- Nel caso in cui si debba installare:
    ```bash 
    winget install --git
    ```

- Aprire la repository su github, e copiare l'indirizzo URL nell'apposita sezione

- Creare una nuova cartella dedicata al contenimento della repo

- Aprire VScode

- Su VScode aprire il terminale (*ctrl+ò*) e accertarsi con il comando 
    ``` bash
    ls
    ```
     di essere nella cartella che si desidera

- inserire il comando 
    ``` bash
    git clone URL
    ```
     della repository

- Una volta clonata la repository sarete pronti ad usare il codice
